# 📚 Jual Buku OSN

Landing page untuk katalog dan penjualan **buku referensi Olimpiade Sains Nasional (OSN)** jenjang **SD dan SMP** dari **LOPI Prestasi Indonesia**.

Website menampilkan berbagai buku referensi, materi, dan latihan soal untuk membantu siswa mempersiapkan diri menghadapi kompetisi OSN.

## ✨ Features

- 📚 Katalog buku OSN SD dan SMP
- 📖 Buku referensi materi dan latihan soal
- 💰 Informasi harga dan produk
- 📱 Responsive untuk desktop dan mobile
- 💬 CTA pemesanan langsung melalui WhatsApp
- 🔍 SEO dasar
- 🖼️ Open Graph untuk social sharing
- 🌐 Favicon
- 🤖 `robots.txt`
- 🗺️ `sitemap.xml`

---

## 🛠️ Tech Stack

- CSS3

- Cloudflare Pages

## 🎯 Purpose

Project ini dibuat sebagai landing page sederhana untuk memudahkan calon pembeli menemukan dan memesan buku referensi OSN dari LOPI.

Fokus utama website adalah menyediakan katalog buku berdasarkan jenjang pendidikan dan bidang yang tersedia, kemudian mengarahkan calon pembeli untuk melakukan pemesanan melalui WhatsApp.

---

## 📚 Product Category

### 🟢 Buku OSN SD

Buku referensi untuk siswa Sekolah Dasar yang ingin mempersiapkan diri menghadapi Olimpiade Sains Nasional.

### 🔵 Buku OSN SMP

Buku referensi untuk siswa Sekolah Menengah Pertama yang ingin mempersiapkan diri menghadapi Olimpiade Sains Nasional.

---

## 🔗 Deployment

Website direncanakan untuk menggunakan Cloudflare Pages sebagai platform deployment.

---

## 📌 Notes

Project ini merupakan landing page statis dan tidak menggunakan database atau backend.

Informasi produk, harga, dan katalog dikelola langsung melalui file website.
